DBMS Relational Schema & Integrity Constraints

Foreign keys and duplicate clustering normalization

Table: complaints (Master)

  • • complaint_id [PK] (VARCHAR)
  • • title (VARCHAR)
  • • category_id [FK] → categories
  • • dept_id [FK] → departments
  • • ward_id [FK] → wards
  • • cluster_id [FK] → clusters
  • • priority_score (INT)
  • • status_enum (NEW, READY, ASSIGNED, RUNNING, RESOLVED)

Table: status_history (Audit Trail)

  • • history_id [PK] (INT AUTO_INCREMENT)
  • • complaint_id [FK] → complaints
  • • from_status (VARCHAR)
  • • to_status (VARCHAR)
  • • updated_by (VARCHAR)
  • • timestamp (TIMESTAMP DEFAULT CURRENT_TIMESTAMP)
  • • remarks (TEXT)
